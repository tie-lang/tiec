# p.9.2.3 DAP 调试器（Debug Adapter Protocol）

**状态**：已实现（p.9 工具链 / 编译器侧仓库 tiec）。
**交付**：**调试适配器服务**（DAP JSON-RPC over stdin，驱动 interp 执行器）+ VS Code 客户端示例（launch.json + 最小扩展）。

## 定界（务实裁决）
- **驱动执行器**：compiler/interp 解释器。调试适配器服务 `tiedap.exe` 在 stdin 上
  按 DAP Content-Length 帧通信，`launch` 后用 interp 执行被测程序。
- **运行至完成模型**：interp 为单线程树遍历求值器，无法中途挂起/续行。故一次性跑完
  被测程序收全 interp_dbug 里程碑事件流（C/R/S），按游标 `td_cursor` 在事件流上移动
  「停止点」服务断点/单步/调用栈。
- **断点（行级）**：被测程序把 `type tie<...>` 角色头替换为注释行（保留行号）→
  interp_dbug 记录语句行。断点命中该行首个 (S) 语句，或函数身体首条的 (C) 入门事件
  （函数体首条语句行由 C 承载，S 不重复发——保证行断点命中可靠）。
- **单步**：`next/stepIn`→下一局部 (S) 事件；`stepOut`→深度更低的下一个 (S) 事件；
  `continue`→下一断点行；无更多断点→`terminated`。
- **调用栈**：由事件流重建（当前函数帧 + 函数体首行），`stackTrace` 返回。
- **变量**：`variablesReference=1` 的 **Global** 作用域来自 interp 全局表
  （isess g_keys/g_vals + ivalue 类型）。**局部变量不可得**（运行至完成模型下作用域已
  弹出）→ scopes 返回 `Locals (unavailable)`，本地作用域接口预留。
- 支持命令：`initialize / setBreakpoints / launch / configurationDone / threads /
  stackTrace / scopes / variables / continue / next / stepIn / stepOut / disconnect`。

## 交付物
| 文件 | 说明 |
|------|------|
| `compiler/dbug/tiedap.tie` | DAP 适配器服务（tiec→tiedap.exe） |
| `compiler/dbug/_dap_probe.tie` | DAP 验收探针 |
| `scripts/verify-tiedap.ps1` | 验收脚本（模拟 DAP 客户端收发帧） |
| `.vscode/launch.json.example` | VS Code launch 配置示例 |
| `vscode-ext/tie-dap/` | 最小 VS Code 调试扩展（拉起 tiedap.exe） |

## 协议传输
Content-Length 帧（`Content-Length: <字节长>\r\n\r\n<json>`）。二进制 stdin 读
（stdin_read 字节流）+ stdout 写（stdout_write_str）。帧头解析、字符串/整数字段
提取（`fj_*`）均为手写极简实现——**import 非 std/json.tie**：interp 自带 parser
已声明全局 `g_pos`，json.tie 亦声明 `g_pos`，同编译单元合并会「全局变量重复定义」
（E00285），故不引入 json 命名空间（见 tiedap.tie 头注释）。

## 用法
```
# 构建适配器服务
tiec compiler\dbug\tiedap.tie -o compiler\dbug\tiedap.exe
# 验收（PowerShell 模拟 DAP 客户端）
pwsh ./scripts/verify-tiedap.ps1
```
VS Code 调试 tie 程序：
1. 构建 tiedap.exe（上文）。
2. 安装最小扩展 `vscode-ext/tie-dap/`（拷到 `~/.vscode/extensions/` 或
   `code --install-extension` 指向该目录），重启 VS Code。
3. 项目 `.vscode/launch.json` 用 `launch.json.example` 的 `type:"tie"` 配置。
4. 打开目标 `.tie` 源文件，F5。支持：行断点 / continue / 单步 / 调用栈 / 全局变量。

## 限制（诚实说明）
- **局部变量不可用**：运行至完成模型无法在断点处给出函数局部；后续若将解释器改为
  增量求值（suspend/resume），可接入 Local scope 与实时变量。
- **被测程序在调试会话内不应直接 println** 到 stdout（当前进程内驱动、运行至完成，
  无法把程序 stdout 分离为 DAP `output` 事件）；输出请用全局变量经 `variables` 观察。
- **编译器自身崩溃的符号化**见 p.9.2.1（本子项不涉及）。

## 验收
`pwsh ./scripts/verify-tiedap.ps1`：initialize→initialized；setBreakpoints(line11)；
launch；configurationDone→stopped(reason=breakpoint)；stackTrace 含 compute/main 帧；
variables 含 g_count/g_msg；continue→terminated；disconnect。（帧解析按字节长度，兼容
中文变量类型名）
